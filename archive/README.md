# Archive

Kept so the previous site can be restored without digging through git.

- `vcard-site/` — the site as it was before the September 2026 redesign (dark "vCard" template: `index.html`, `style.css`, `script.js`, plus the even older `original_index.html` and `replit.md`). To restore: copy `index.html`, `style.css`, `script.js` back to the repo root. Asset paths in these files are relative to the root, so they will not render correctly from inside this folder.
- Design alternatives from the redesign live in `design/`:
  - `design/mockup-v1.html` — dark editorial direction (not chosen)
  - `design/mockup-v2.html` — retro direction (chosen, became the live site)
  - `design/shots/` — before/after screenshots

Both `archive/` and `design/` are excluded from search engines via `robots.txt`.
