# Visual Overhaul Changelog — `veilbreaker.html`

This overhaul is **visual-only**: gameplay logic, controls, enemy AI, HUD, Web Audio synthesis, combat timings/balance, `localStorage` preferences, and the shapes of `game`, `player`, and `enemy` objects are strictly preserved.

---

## Replaced & Upgraded Functions

| Function / System | Before (Procedural) | After (Stylized PBR + GLB + Post-Processing) |
| :--- | :--- | :--- |
| `<script type="importmap">` & imports | `three` only | Added `"three/addons/"` mapped to `three@0.164.1/examples/jsm/`; imported `GLTFLoader`, `RGBELoader`, `MeshoptDecoder`, `SkeletonUtils`, `mergeGeometries`, `EffectComposer`, `RenderPass`, `UnrealBloomPass`, `ShaderPass`, `SMAAPass`, `OutputPass`. |
| `createNightCityEnvMap()` / Sky & IBL | 256×128 canvas PMREM + solid `#090d1a` background | Retained `createNightCityEnvMap()` as fallback; added `applyHDREnvironment()` loading `assets/sky/night_sky.hdr` via `RGBELoader` → `PMREMGenerator` for both `scene.environment` and `scene.background`, plus `buildCelestialSky()` (moon billboard, twinkling star dome, drifting cloud cards) and retuned `FogExp2` (`#090e1c`, density `0.0135`) and `camera.far = 260`. |
| Render pipeline (`QUALITY_PRESETS`, `applyQualityPreset`, `resize`, `loop`) | Direct single-pass `renderer.render()` | Added `buildComposerForPreset()` and `disposeComposer()` with `RenderPass` → selective high-threshold `UnrealBloomPass` (`threshold: 0.94`, strength `0.40–0.48`) → custom `VignetteGradeShader` `ShaderPass` → `OutputPass` → `SMAAPass` (`high`). Wired into presets: `low` = direct render & no shadows (no bloom on touch low); `mid` = 4× MSAA `HalfFloatType` target + half-res bloom; `high` = full-res bloom + `SMAAPass`. Properly disposes targets/passes on preset switch and resizes cleanly. |
| `makeGroundPBRTextures()` & `makeArchitecturalStoneTextures()` | 512px/256px canvas textures with `bumpMap` | Retained both functions as fallbacks (`getFallbackGroundPBR()`, `getFallbackStonePBR()`). Upgraded plaza ground, sanctum dais, and sidewalks/planters to Poly Haven tileable PBR sets (`albedo + normalMap + ORM/ARM`, `uv1` copied for `aoMap`, max anisotropy), with `_512.webp` auto-selected on touch devices (`IS_TOUCH`). |
| `buildWorld()` | Primitive geometry buildings, cars, lamps, barriers, trees, rocks, grates, and cylinder skyline | Rebuilt using `cloneNormalizedGLB()`, `addInstancedGLBProp()` (`InstancedMesh`), and `mergeGeometries()`: GLB entry archway (`arch_gate.glb`) with emissive neon sign; GLB cover & sanctum columns (`pillar.glb`, `pillar_broken.glb`) preserving exact `obstacles` & `addOccluder` fade; GLB trees & bushes (`tree_lush.glb`, `tree_dead.glb`, `bush.glb`) in merged planters; physical clearcoat cars (`car_sedan.glb`, `car_police.glb`) with glossy tinted physical glass and volumetric headlights; instanced streetlights (`lamp_street.glb`, `lamp_double.glb`) with soft Fresnel/vertical-gradient shader light cones; instanced sidewalk furniture (`bench`, `dumpster`, `firehydrant`, `rail`, `sign_hazard`, `sign_neon`, `barrier`, `rock`, `candelabrum`, `candles`, `statue`, `stairs`); merged ground decals (clearcoat puddles, weathered cracks, cast-iron manholes, lane paint); instanced perimeter modular buildings with merged lit windows; and a 3-layer merged distant skyline (`buildMergedSkyline()`). Kept `RITUAL_FS` altar shader and all procedural builders as automatic fallbacks. |
| `buildCharacterRig(kind)` | Primitive Capsule/Sphere/Lathe rigs | Original procedural builder preserved as `buildProceduralCharacterRig(kind)` fallback. New `buildCharacterRig(kind)` clones cached skinned GLBs via `SkeletonUtils.clone`, normalizes height via `Box3` (`y = 0` feet, standing height `2.04` before `1.06` player / `1.58` boss scale, `+Z` forward), applies per-instance cloned PBR materials + hit-flash `flashMats`, hue-shifts player cloak to midnight sapphire-cyan/gold (`getPlayerMidnightTex()`), hides built-in dagger/crossbow, mounts separate glowing weapon GLBs (`pistol.glb` with muzzle flash, `katana.glb`, `grimoire.glb`, `cleaver.glb`, `spear.glb`, `greatsword.glb`) on hand bones (`handslot.l` / `handslot.r`), adds optional skeleton-bound inverted-hull outlines behind `STYLE.outline`, and adds MALAKOR's curved horns, dual-ring halo, and vertex-shader swaying tattered cape (`createBossSwayingCape()`). Exact return shape `{ root, inner, torso, head, armL, armR, legL, legR, flashMats, hpBar }` and all `inner.userData` hooks preserved. |
| `animatePlayerRig(dt)` & `updateEnemies(dt)` | Primitive joint-group rotations | Added `createRigAnimController()`, `playRigClip()`, and `updateEnemySkinnedAnim()` driving one `THREE.AnimationMixer` per character with `0.08–0.18s` crossfades, `timeScale` fitted to `stateDur` so gameplay timings and hit frames match 1:1, driven by scaled `dt` (preserving hit-stop and slow-mo). Added procedural left-arm pistol aim/recoil bone layer after `mixer.update(dt)`. Preserved procedural animation path for fallback rigs. Extended `loop()` to play `Death_A` / `Death_B` in `dead`/`win` modes and `Skeletons_Awaken_Standing` during boss `cine` mode. |
| `clearEntities()` & hot-loop allocations | Minimal cleanup; per-frame `Vector3`/`Color` allocations | Added `disposeObjectMaterials()` and `mixer.stopAllAction()` cleanup in `clearEntities()`; hoisted scratch vectors (`_camTargetLook`, `_camTargetPos`, `_pPosPrev`, `_enemyPrevPos`, `_sparkCol`) out of per-frame loops; converted `floatingShards` to an `InstancedMesh` and guarded raindrops from passing right in front of the camera lens. |
| Startup (`bootGame()`) & Title Screen | Synchronous procedural build | Added `LoadingManager`, `ASSETS` cache, and title-screen progress bar. `#btn-start` stays disabled until Phase A critical assets (sky HDR, ground/sanctum PBR, arena props, player + weapons) finish loading and compile via `renderer.compileAsync()`. Streams enemy/boss GLBs in Phase B, pre-warms one hidden instance of each enemy with `compileAsync()` to prevent first-spawn hitches, and falls back gracefully with `console.warn` on `file://` or load errors. |
| `updateF3(rawDt)` | `calls` and `triangles` only (reset per composer pass) | Disabled `renderer.info.autoReset`, reset once per frame around rendering to capture true full-frame totals, and added `Tex` (`renderer.info.memory.textures`) and `Geo` (`renderer.info.memory.geometries`) to the F3 telemetry overlay. |
